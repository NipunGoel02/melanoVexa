RESEARCH QUESTION

How does focal loss change the SCC sensitivity vs macro-F1 trade-off?

Controlled EfficientNet-B0 ablation · same data split, weighted sampler and optimizer

PILOT RESULTS
01 · OBSERVED GAPRare SCC class

SCC is 376 / 5,082 training images (~7.4%). Overall accuracy can hide missed SCC cases.

02 · PILOT FINDINGAttention misses SCC

At macro-F1-selected checkpoints, both attention variants had 0 SCC recall. Plain CE reached 67.0% on this internal split.

03 · NEW ABLATIONFocal loss did not fix it

Attention + focal changed macro-F1 by just 0.0011 vs attention + CE; SCC recall stayed at 0. This is a failure analysis result, not a model improvement claim.
